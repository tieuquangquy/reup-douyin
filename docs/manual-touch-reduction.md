# Manual Touch Reduction

Manual touch reduction identifies where the operator spends time.

## Current Hotspots

The phase 1 summary groups:

- transcript review flags
- translation review flags
- open risk flags
- publish reconciliation drafts
- publish failures

## Purpose

The goal is to guide what to improve next:

- tune source selection when transcript flags are high
- tune translation or TTS prep when translation flags are high
- tune risk scanners when false positives are common
- inspect account/page health when publish failures cluster

## Limits

The system does not yet measure exact edit time or keystrokes. It uses stored warning flags and workflow states as proxies.
