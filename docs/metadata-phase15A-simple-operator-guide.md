# Phase 15A Simple Operator Guide

## Normal flow
1. Open profile page and click **Smart Capture & Harvest**.
2. Open a modal video.
3. Click **Calibrate 4 Points** if calibration is missing.
4. Click **Test Current Video**.
5. Click **Resume** to continue harvest.
6. Use **Stop** only when harvest is running.

## Advanced Diagnostics
Open **Advanced Diagnostics** only for troubleshooting:
- Capture current page only
- Reset Harvest State
- Show Runtime Transitions
- Reset Calibration
- Factory Reset Extension
