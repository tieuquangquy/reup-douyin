# Subtitle Generation

Subtitle generation creates render-ready Vietnamese subtitle data from current edited translation segments.

## Canonical Model

`SubtitleSegment` rows are the canonical subtitle timeline for the app. JSON and SRT assets are exports of the current DB rows for render and debugging.

Important fields:

- `source_video_id`
- `translation_segment_id`
- `segment_index`
- `start_ms`
- `end_ms`
- `text`
- `layout_mode`
- `track_kind`
- `review_flags_json`
- `subtitle_version`
- `is_current`

## Layout Metadata

Phase 1 uses simple render hints:

- `layout_mode = bottom_safe_area`
- `track_kind = vietnamese_hard_burn`
- `line_break_strategy = balanced_18_chars`
- `max_chars_per_line = 18`

Render engine can interpret these hints without needing editor-specific logic.

## Output Formats

The pipeline writes:

- `SUBTITLE_JSON`: canonical render-friendly JSON
- `SUBTITLE_SRT`: interoperability/debug format

ASS is reserved in the enum but not generated by default in phase 1.

## Versioning

Rerun strategy:

- Previous subtitle rows become `is_current = false`.
- New rows receive `TTS_PIPELINE_V1_RUN_N`.
- New subtitle assets become current media assets.

## Phase 1 Limits

- No visual subtitle designer.
- No OCR-aware placement.
- No hard-burn rendering.
- No automatic line-break optimization beyond metadata hints.
