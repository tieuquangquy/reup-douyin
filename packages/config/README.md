# packages/config

Shared configuration conventions and templates for `reup-douyin`.

## Responsibility

- Document environment variable naming and shared config expectations.
- Hold safe templates and examples only.
- Keep local development defaults separate from production requirements.

## Boundaries

- Do not commit secrets.
- Do not place app runtime logic here.
- Do not encode business workflow decisions as configuration shortcuts.

## Current Status

Bootstrap placeholder only. Config templates will be expanded when runtime implementation begins.
