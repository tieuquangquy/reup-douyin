    Compact guarded pipeline: export emits only counts, verdicts, blockers, source IDs, artifact availability, safety booleans, and the exact next action. The runner skips already-passed artifacts and stops on the first blocker.
    
              
    Per-batch milestone authority diagnostic: read-only export showing, per pilot batch size (10 and 50), which milestone alias/artifact resolved and why. Milestone authority is additive and batch-scoped, so a later batch (Pilot 50) never overwrites or invalidates an already-passed earlier batch (Pilot 10, Queue Completion 10). It emits resolution source, ignored shared-alias reasons, milestone blockers, and the highest passed milestone; it does not rerun stages or mutate storage.
    
              
    Full queue completion dry-run: read-only pre-flight before enabling full queue completion. It does NOT enable full_queue_completion, performs no backend writes, and does not mutate the queue or collect_job. Coverage is now SCALE-INDEPENDENT: a live chunked backend verify against /douyin-extension/capture-inbox/items/verify drives backend_backed_count / queue_total at any N (50, 126, 1000, ...). Pilot 50 post-verify is kept only as a one-time mechanism-validation precondition, not the coverage authority. Items not yet backend-backed remain pending and are listed under not_backend_backed_pending_aweme_ids_sample. The dry-run reports exact_aweme_id_only match accounting, the Pilot 50 gap (informational), and a go/no-go readiness verdict with blockers.
    
              
    Full queue completion executor flag: fullQueueCompletionEnabled · Current value: local extension setting, default false · The executor runs only when explicitly enabled by the operator. It does NOT collect missing videos. It only MARKS already-backend-backed pending queue items as status=backend_verified, capture_status=complete using exact_aweme_id_only matching against the LIVE backend, in resumable chunks of 500. Re-running never double-marks; items without a live backend record stay pending; on 401/auth_required it pauses safely and resumes after re-auth.
    
              
    Guarded pipeline storage inventory: read-only diagnostic across local/session/sync storage keys. It emits key existence, top-level keys, compact IDs, batch fields, verdict/status fields, item counts, blocker counts, and timestamp presence only; it does not run guarded stages or mutate production state.
    
              
    Backend shadow row evidence: read-only local artifact export from the latest backend shadow artifact. It emits accepted/rejected counts plus the first 5 sanitized rows with outgoing payload title/raw Likes evidence, no raw IDs, no thumbnails, no backend calls, no production beta, and no storage mutation.
    
              
    Beta production row evidence: read-only local artifact export from the latest guarded beta production artifact. It emits sanitized first 5 title/raw Likes payload and read-back fields, no raw IDs, no thumbnails, no backend calls, no beta rerun, no Pilot action, and no storage mutation.
    
              
    Pilot 50 backend evidence dump: read-only authenticated backend read for the 50 verified Pilot 50 aweme_ids against the current backend. It issues scoped (by capture_session_id) and unscoped (aweme_id only) verify lookups and emits per-id found yes/no with present fields, scoped_found_count / required, and a verdict of backend_backed vs artifact_only so you can tell whether Pilot 50 is backend-backed right now or passing only from stored artifacts. No writes, no pipeline rerun, no pilot auto-rerun, no full queue completion, and no estimated_views change.
